matveevVpn 1.0.1 for macOS (Apple Silicon)
==========================================

matveevVpn is a universal selective-routing VLESS client. Enter your own
subscription URL during setup and select a node. The built-in routing editor lets
you change which domains or applications use the tunnel; the full sing-box JSON
is generated automatically.

Every reinstall starts from a fresh subscription and node selection. A recognized
previous ~/VPN installation is moved to a timestamped backup before new files are
created, so old configuration files cannot affect the new installation.

All normal controls and routing-rule editing are available in the native
matveevVpn window. Use Uninstall… in the app to remove it completely.

The administrator password is requested once during initial system setup. Normal
on, off, restart, and routing-rule updates do not request it again.

Includes sing-box 1.13.19 arm64, its GPL-3.0-or-later license and source archive.
The app uses a local ad-hoc signature and is not notarized by Apple.
