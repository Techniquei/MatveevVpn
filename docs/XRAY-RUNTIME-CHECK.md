# Первый шаг новой беты: проверка libXray

Статус: прототип, не опубликованный релиз. Текущий VPN и UI ещё не переключены.

## Что уже реализовано

- Отдельный процесс с libXray/Xray-core 26.9.30, закреплёнными go.mod/go.sum
  и Go 1.27.1. Go хранится локально в .build, системная установка не нужна.
- Ограниченный JSON-протокол через stdin/stdout: start, validate, stop, status.
  Конфигурация не попадает в аргументы, ошибки не повторяют значения из неё.
- Проверки передачи HTTP через локальный SOCKS, освобождения сокета,
  запрета валидации рядом с работающим ядром и завершения при EOF/SIGTERM.
- Конструирование конфигураций RAW, TLS, WS, gRPC, REALITY и XHTTP TLS/REALITY.
  Это проверка совместимости схемы, не соединения с реальными серверами.

Сборка и проверки:

```sh
cd /Users/vladimir/Documents/matveevVpn
bash Scripts/test-xray-runtime.sh
./Scripts/validate.sh
```

Worker пока не устанавливается как системный компонент. Его конфигурация
предназначена для доверенного родителя; ограничение root-полей и публичный IPC
появятся в нативном сервисе. Этот прототип не следует подключать к launchd
или использовать вместо действующего VPN.

## Ручная проверка TUN

На этом шаге проверяем только создание и удаление интерфейса Xray на настоящем
Mac. Проба не проверяет DNS, маршрутизацию сайтов или связь с VPN-сервером.
Для чистого результата выключите текущий VPN, затем выполните:

```sh
sudo /Users/vladimir/Documents/matveevVpn/.build/xray-runtime/matveev-xray-runtime --tun-smoke
```

Пароль вводится в Terminal, не в чат. Команда принимает только фиксированный
тестовый режим: создаёт свободный utun900–utun999 с link-local адресом,
останавливает ядро и проверяет удаление интерфейса. Она не меняет системный
DNS, не добавляет маршрут по умолчанию, не устанавливает daemon и не читает
подписку. Общий предел ожидания и shutdown — 15 секунд.

Ожидается одна JSON-строка:

```json
{"check":"tun","core":"26.9.30","interface":"utun900","created":true,"released":true}
```

Номер интерфейса может отличаться. Успех: created и released равны true,
поля error нет, обычный Интернет после пробы работает. После проверки можно
снова включить прежний VPN.

При ошибке пришлите строку результата и сообщите, вернулся ли Интернет.
Не отправляйте подписки или приватные конфигурации. Если команда прервётся
по таймауту без результата, это не считается успешной проверкой.
